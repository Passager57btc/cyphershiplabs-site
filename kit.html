The Blueprints / Crew Kit

Stop re-explaining your project to your AI every session.

The Crew Kit is the method we use at CypherShip Labs to work with a small team of AI agents, each with its own role, its own memory and its own rules. Blank templates you copy and name yourself, plus an installation guide, for Claude Code (and ChatGPT / Codex).

In preparation. Not for sale yet: you can sign up to be told when it is ready. Target: end of 2026, date to be confirmed.

The problem

The problem, from your side

You already use Claude Code or ChatGPT. It works well… for one session. The next day, the AI no longer knows where you left off, you paste the context back in, two conversations contradict each other, and you can’t tell which one is right.

It isn’t a model problem. It’s an organization problem: nobody decided who does what, where memory lives, or who is allowed to change what.

We had this problem. We solved it by building our own crew of agents, with its own rules, over months of real work. The kit is that structure, cleaned up so you can pick it up without reinventing it.

In the kit

What’s in the kit

01

Blank agent templates

Files to copy into your project, one per role: architect, developer, reviewer, documentation writer, researcher, and a few more. Technically, they are Claude Code subagent definitions. Each template states the mission, what the agent may do, what it must not do, and how it reports back.

02

Persistent memory

A “second brain” in plain text files versioned with git, an index that says where to find what, and the “current state” + archive pattern, so memory stays short to read without losing any history.

03

Working rules

  • one writer at a time on the memory;
  • relaying a message is not approving it;
  • a second read before anything ships;
  • “no light without proof”: nobody says “done” without having checked;
  • a written handoff when you switch models (Claude to GPT, and back).
04

A written installation guide

Step by step, for Claude Code, with adaptations for ChatGPT / Codex.

It’s not a video course, and it’s not a class. It’s a folder of files and a guide to read, which you install in an evening or two.

Important: the kit contains blank templates

You name and build your own crew. Our names, our portraits and our memory are not included. The templates are role skeletons: you choose the names, the personality and the rules that suit you, and you fill your own memory as you work.

Scope

What the kit is, and is not

The kit IS

A dependable way of working for a small team of named agents, with:

  • roles defined as Claude Code subagents, and a CLAUDE.md file that sets the project’s rules;
  • persistent memory in plain text files, versioned with git, read at the start of every session;
  • review loops (one agent reads another’s work, including through a pull request before merging);
  • written handoffs between models (Claude, GPT/Codex);
  • the one-writer-at-a-time rule on memory;
  • a verification standard: nothing is declared “done” until it has been checked.

The kit IS NOT

A swarm of autonomous agents running 24/7 on a server. We work session by session, on purpose, with a human in the loop: you decide, you launch, you validate. Running agents around the clock is a different subject, and the kit does not cover it.

It’s less spectacular than a swarm. It’s also what let us deliver real work without losing the thread.

Our story

How it works

Your crew is a small team where every agent has a clear role. Here is ours, told as our story: you will build yours, with your own names.

  • Noos orchestration Holds the overall context and coordinates.
  • Achille direction Holds the trajectory and arbitrates when two opinions differ.
  • Nestor research Goes out to find the information, with sources.
  • Daedal architecture Thinks through the structure before anything gets built.
  • Noah building Writes the code, nothing else.
  • Paris review Tests and challenges before anything leaves.
  • Ulysse planning Organizes the work over time.
  • Hector documentation Writes down what was decided, so the team remembers tomorrow.
  • Minos deadlines Tracks dates and obligations.
  • Iris words Writes what goes out to the outside world.
  • Thalie visual creation Image, identity, interface.

Everyone reads the same memory at the start of a session and writes down what’s worth keeping at the end. You stay the one who decides.

One measurement from our own setup: by restructuring the memory (a short “current state” plus a separate archive), the files read at startup went from 143 KB to 40 KB, about 26,000 fewer tokens per session by our estimate. That is the order of magnitude of our own memory, not a promise for yours: the gain depends on how large your history is.

Who it’s for

  • You’re independent, a freelancer or a solo founder.
  • You already use Claude Code or ChatGPT every day.
  • You lose time recovering context from one session to the next.
  • You’re comfortable copying files and following a guide; you don’t need to be a developer.

Who it’s not for

  • If you’ve never opened Claude Code or ChatGPT: use them for a few weeks first, the kit will be more useful afterwards.
  • If you want a one-click, turnkey tool: this is a method and a set of files, not software.
  • If you want agents that run on their own, nonstop, on a server: that’s not what the kit is about.
  • If you expect guaranteed results: a well-organized crew helps, but it replaces neither your judgment nor your review.

No, but you need to be comfortable copying files into a folder and following a guide. The guide is written for someone who isn’t a developer. The technical vocabulary (subagents, CLAUDE.md, git) is explained as you go.

The main guide is written for Claude Code. It includes adaptations for ChatGPT / Codex. The templates are plain text files, so the principle carries over, but the exact installation depends on the tool.
